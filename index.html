Known blockers
HIGH
Apple Developer Account costs ₹8,300/year — delay until Month 4. Use Expo Go for all testing before then.
HIGH
Solo developer — scope is your enemy. Never add a feature mid-phase. Finish the phase, then reassess.
MED
Supabase free tier pauses after 7 days inactivity. Set cron-job.org ping immediately.
MED
Claude API costs rise fast without caching. Build food cache in Phase 2 before opening to users.
LOW
Widget is hardest technical feature — native code required. Defer to v2 no matter how tempting.
LOW
Strava API rate limit: 100 requests/15 min, 1000/day. Design polling to batch, not per-user-open.
Personal rules — read when overwhelmed
01
One screen. One week. Use it yourself. Then the next screen.
02
Never add a feature that isn't on the scribble pad. New ideas go in a backlog, not into the current build.
03
If you haven't opened the app yourself in 3 days, stop building features and fix whatever's making you avoid it.
04
Survey responses first, code second. Real users beat assumptions every time.
05
Use Haiku for everything until you have a reason not to. Sonnet is for weekly reports only.
06
Commit to GitHub every single session, even if it's 20 lines. The commit history is your progress journal.
07
When college gets heavy, maintain not build. Open the app, log your own food, check the streak. Don't go dark.
